# Înlocuirea proiectului vechi în GitHub

Cel mai simplu este să încarci conținutul acestei arhive într-un repository curat.

Dacă păstrezi repository-ul existent, șterge fișierele vechi care se suprapun, apoi încarcă toate folderele din această arhivă, inclusiv folderul ascuns `.github`.

După commit pe `main`, mergi la `Actions` și deschide `Build AI Stoica Windows`.

Nu încărca fișiere `.env`, chei API, cookie-uri, parole sau token-uri private.
